## Code of Conduct

This project and everyone participating in it is governed by the [News Analyzer Code of Conduct](CODE_OF_CONDUCT.md). By participating, you are expected to uphold this code.

## I Have a Question

Before you ask a question, it is best to search for existing [Issues](https://github.com/GVN2307/News-Analyzer/issues) that might help you.

If you then still feel the need to ask a question and need clarification, we recommend the following:

- Open an [Issue](https://github.com/GVN2307/News-Analyzer/issues/new).
- Provide as much context as you can about what you're running into.
- Provide project and platform versions (nodejs, npm, etc), depending on what seems relevant.

## I Want To Contribute

### Reporting Bugs

- Ensure the bug was not already reported by searching on GitHub under [Issues](https://github.com/GVN2307/News-Analyzer/issues).
- If you're unable to find an open issue addressing the problem, [open a new one](https://github.com/GVN2307/News-Analyzer/issues/new). Be sure to include a title and clear description, as much relevant information as possible, and a code sample or an executable test case demonstrating the expected behavior that is not occurring.

### Suggesting Enhancements

- Open a new [Issue](https://github.com/GVN2307/News-Analyzer/issues/new) to suggest an enhancement.
- Describe the current behavior and explain which behavior you expected to see instead and why.

### Pull Requests

1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.
6. Issue that pull request!
